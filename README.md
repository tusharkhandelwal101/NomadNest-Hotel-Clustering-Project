# 🏨 Hotel Customer Segmentation - NomadNest Retreats

A data analytics project aimed at segmenting hotel customers for a fictional hotel chain using clustering techniques. Built using the CRISP-ML(Q) framework, this project combines SQL, Python, and Power BI for full-cycle analysis.

## 🚀 Objective

To segment hotel guests based on booking and behavioral patterns to enable data-driven decision-making, targeted marketing, and improved profitability.

---

## 🧠 CRISP-ML(Q) Steps Followed:

1. **Business & Data Understanding**  
2. **Data Dictionary Creation**  
3. **EDA & Pattern Identification**  
4. **Data Preprocessing (SQL + Python)**  
5. **Model Building (KMeans Clustering)**  
6. **Cluster Profiling & Power BI Visualization**

---

## 🛠️ Tools & Technologies

- **MySQL** – for initial data storage and preprocessing  
- **Python (Pandas, Sklearn, Matplotlib)** – for clustering and analysis  
- **Power BI** – for building an interactive dashboard

---

## 📊 Power BI Dashboard

- Cluster-wise KPIs: Revenue, Occupancy, CAC, Feedback  
- Filters by City, RoomType, Cluster  
- Cluster segment insights and patterns
